上周调试 test_user 最后失败的原因是因为 test_user.c 我编译的时候没有加调试参数，导致

```json
  Breakpoint 1140, 0xffffffc080368812 in enter_user ()                                                                           
  add symbol table from file "/home/iristseng/data/StarryOS/user_apps/test_user" at                                              
      .text_addr = 0x10258                                                                                                       
  Reading symbols from /home/iristseng/data/StarryOS/user_apps/test_user...                                                      
  (No debugging symbols found in /home/iristseng/data/StarryOS/user_apps/test_user)
```

因为当前我用的这个StarryOS中没有C 用户程序的编译流程，所以我还是在 ubuntu中编译的test_user.c，然后挂载到StarryOS中的：

```shell
// 当前这个 StarryOS 没有 glibc 动态库，所以静态编译
cd /home/iristseng/data/StarryOS/user_apps && riscv64-linux-gnu-gcc -g -static test_user.c -o test_user

// 挂载
mkdir -p /mnt/starry && mount -o loop /home/iristseng/data/StarryOS/make/disk.img /mnt/starry && cp /home/iristseng/data/StarryOS/user_apps/test_user /mnt/starry/test_user && umount /mnt/starry
```
