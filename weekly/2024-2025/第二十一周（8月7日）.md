- 解析poll函数

	工具：src/core/find_poll_fn.py

	```shell
	# 输入一下命令：
	gdb -batch \
	  -ex "source src/core/find_poll_fn.py" \
	  -ex "find-poll-fn" \
	  -ex "set pagination off" \
	  --args tests/tokio_test_project/target/debug/tokio_test_project
	```

	遇到了一下报错：

	```shell
	Python Exception <class 'ModuleNotFoundError'>: No module named 'core'
	Error occurred in Python: No module named 'core'
	```

	这个报错原因是因为 GDB 内置的 python 解释器无法找到我们项目内的 `core` 模块，这需要我们手动引入。

	我们这个项目的src下需要安装一些第三方依赖，所以之前创建了一个虚拟环境，所以我们可以直接往我们的虚拟环境中设置 PYTHONPATH 。

	具体设置步骤：
	```shell
	# 进入项目目录
	cd ~/data/code-debug_Asynchronous-trace/src
	
	# 激活虚拟环境
	source venv/bin/activate
	
	# 设置 PYTHONPATH
	export PYTHONPATH="venv/lib/python3.12/site-packages:$PWD:$PYTHONPATH"
	
	# 验证路径是否生效
	python -c "import sys; print(sys.path)"
	```

	设置成功后运行命令还是不行，后面检查python代码才发现是命令没注册成功，忘记在模块末尾调用类构造函数来注册这个命令，修改后成功获得poll_map.json
